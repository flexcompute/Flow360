To update the compatibility matrix follow these steps:

1. Edit Excel File
	-> Any new footnote should have <sup>9</sup> in the table without any spaces and :sup:`9` in the footnote list with a space for formatting purposes (example shown for a note with number 9).

2. Export CSV file with , as a field delimiter and " as a string delimiter.

3. Run featureCompatibilityMatrix.py -> this will generate the featureCompatibilityMatrix.rst file automatically
