# Dashboard

*The Flow360 GUI dashboard serves as the central hub for managing and monitoring your computational fluid dynamics (CFD) projects. This interface provides an intuitive overview of your simulations, resources, and project status.*

---

## Dashboard Components

| *Component* | *Description* |
|--------------|-----------------|
| **Recent** | Grid view of recent CFD projects with status indicators. |
| **FlexCredits** | Display of available computation credits. |
| **Company-wide storage** | Storage usage bar showing your company's current consumption against its allocated limit. |
| **Pending resources** | Overview of computational resources in use, diverged, or failed. |
| **Start with the example** | Use a pre-prepared example to get accustomed to Flow360. |
| **Search** | Find folders, projects, reports and assets by name or ID. |

```{seealso}
For the workflow and interface overview, see the {doc}`User Guide: Workflows & Interfaces </user_guide/WorkflowsInterfaces/WorkflowsInterfaces>`.
```

## Detailed Descriptions

### Recent

*The main area displays a grid of recent project cards, showing your latest CFD simulations in chronological order.*

- **Information shown for each project:**
  - Project name and description
  - Number of surface meshes, volume meshes and cases
  - Divergence and error indicators
  - Last modification timestamp
- **New project button:**
  - Create a new project
- **Refresh button:**
  - Manually refresh all project resource statuses
  - Located next to New project button

### Search

*Finds folders, projects, reports and assets across your work, opened from the search icon in the sidebar.*

- **Search by:** name or ID.
- **Match mode:** `Contains` matches anywhere in the name, `Exact match` requires the whole value.
- **Items:** restrict the search to any combination of `Folder`, `Project`, `Report` and `Asset`. All four are searched by default.
- **Tag:** restrict results to one or more tags.
- **Scope:** search the current workspace, or every workspace you have access to. Results name the workspace they were found in.
- **Results** are grouped by item type, and each entry shows the folder path it sits in so identically named items can be told apart.

### FlexCredits

*Shows your current balance of computation credits.*

- **Balance:** Numerical value of your current FlexCredit balance.
- **Updates:** Credits are consumed based on computational resources used.

### Company-wide storage

*Displays your company's total storage consumption relative to its allocated limit. This widget appears on the dashboard only for companies that have a company-wide storage agreement with Flexcompute.*

```{image} ./Figures/company_wide_storage.png
:alt: Company-wide storage widget showing usage bar and current/total storage values
:width: 400px
:align: center
```

- **Usage bar:** A horizontal progress bar shows the proportion of storage used. The label above the bar displays the current usage and the total limit (e.g. *4.22 GB / 8.00 GB*).
- **Warning at 90% usage:** When storage consumption reaches 90% of the allocated limit, a warning is displayed on the dashboard to alert all users in your company.
- **Overage billing at 100% usage:** When the storage limit is fully reached, any additional storage consumed beyond the allocated limit is billed using the standard storage billing rules.

```{note}
The company-wide storage limit is available depending on your customer agreement. If you do not see this widget, your account uses the standard per-use billing model. Contact Flexcompute support for more information.
```

### Pending resources

*Displays pending computational resources and their current status.*

**Information Shown:**
- Running jobs
- Queue status
- Errors and divergence

```{note}
Below **Pending resources** there is a visual representation of all project's statuses called **Projects**.
```

### Start with the example

*A quick-start option for new users to begin with Flow360.*

**Features:**
- Template for common simulation scenarios
- Complete simulation setup
- Sample geometries and volume meshes

### V1 projects (release-24.2 and older)

*Projects created with Flow360 V1 stay reachable as a read-only historical view. They are not shown among the project cards above: open the **V1 (release-24.2 and older)** tab in the workspace view, next to the **Project view** and **Files view** tabs. The tab is shown only to accounts that worked with V1.*

- **Still available:**
  - Browsing the surface meshes, volume meshes and cases the project contains.
  - **Get info**, to open an item's information.
  - **Edit**, to change an item's name and description.
  - **Download**, to retrieve a mesh or a case result.
  - **Delete**.
- **Disabled:**
  - **Upload new file**, together with its **Upload a surface mesh** and **Upload a volume mesh** entries.
  - **New volume mesh** on a surface mesh, and **New Case** on a volume mesh.
  - **Fork**, **Retry** and **Rerun** on a case.

Hovering a disabled action explains that V1 is no longer supported and that the operation is read-only.

```{note}
To continue working from a V1 case, recreate the setup in a new project. Forking the V1 case is not available.
```
