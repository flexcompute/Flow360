Farfield Specifications
***********************

.. currentmodule:: flow360

:class:`WindTunnelFarfield`
===========================

Wind Tunnel Farfield is a special type of farfield that is used to generate a geometry of a wind tunnel as a simulation farfield. 
Different objects are used to specify its behaviour.
